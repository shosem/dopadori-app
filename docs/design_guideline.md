# デザイン方針(衝動代替アプリ)

> 企画は `app_concept.md`、要件・DBは `requirements.md`、進行計画は `dev_schedule.md` を参照。
> 本ファイルは見た目・トーンの方針に特化する。デザイン比較用モックは `design_proposals.html`(案2を採用)。

---

## 採用した方向性: 「案2 — 親しみ / 安らぎ」(絵文字なし)

3案(シンプル / 親しみ / 洗練)を比較し、**案2(親しみ・安らぎ)をベースに採用**。ただし絵文字は使わない。

### なぜ案2か
- このアプリは、ユーザーが最もつらい瞬間(衝動でそわそわしている時)や、自己嫌悪を感じやすい瞬間(見てしまった記録時)に開くもの。**優しく・安心できる・責めない雰囲気**が、依存の孤独な場面に寄り添う。伴走者のようなトーンを目指す。

### なぜ絵文字を使わないか
- 絵文字は視覚的にちらつき、わずかだが刺激になる(「刺激を足さない」という全体思想と綱引きになる)。
- 「見てしまった/うまくいかなかった」場面で、絵文字は軽薄に見えるリスクがある。**"責めないトーン"と"軽く扱うトーン"は別物**であり、絵文字なしの方がその線引きを守れる。
- ポップさ(温かさ)は、絵文字ではなく **色・丸み・言葉づかい** で表現する。

## デザイントークン(方針)

### カラー
- 背景: 温かいクリーム系(モックでは `#fef6ee`、上部に向けてわずかに明るいグラデーション `#fff2e4`)
- 主アクセント: オレンジ(モックでは `#f0895b`)。衝動ボタン・主要アクション・ストリークの数字など「主役」に使う
- 補助アクセント: くすんだ緑(モックでは `#7fb5a6`)。「代替行動」系のアクションなど、オレンジと役割を分けたい要素に
- 文字色: 濃いブラウン(モックでは `#43352b`)。真っ黒を避け、柔らかさを出す
- サブ文字・補足: くすんだブラウングレー(モックでは `#a58a76`)
- カード面: 白(`#ffffff`)。クリーム背景の上に、丸く柔らかい影(オレンジ味のある淡い影)で浮かせる

### 形・レイアウト
- **丸みを大きめに**(カード・ボタンは角丸大。ボタン ~16–18px、カード ~18–20px 程度)
- カードは白面+淡く柔らかい影で、ふわっと浮かせる
- 余白は詰め込みすぎず、ゆったり

### 書体・言葉
- 書体: 丸みのある柔らかいサンセリフ(丸ゴシック系)。角張った硬い印象を避ける
- 言葉づかい: 優しく、話しかけるように。例:「おかえりなさい」「よくがんばってるね」「スキップしても大丈夫」「どんなきっかけだったかな?」
- ただし過剰に馴れ馴れしくはしない。落ち着いた温かさ

### 絵文字・装飾
- **絵文字は使わない**
- 温かさは色・丸み・言葉で出す。アイコンを使う場合も、線が細く主張しすぎない範囲で

## トーンの原則(全画面共通)

これまでの企画で決めた思想を、見た目・言葉のレベルでも徹底する。

1. **急かさない**: 衝動時に判断を増やさない。任意入力(トリガー・メモ)は小さく、スキップが自然に見えるように(連打後画面の縦比 1:2:7)。
2. **責めない**: 「見てしまった」記録や、ストリークが途切れた時も、色・文言で追い詰めない。「記録しました」「また今日から進めましょう」と淡々と・優しく。
3. **刺激を足さない**: 派手なアニメーション・強い効果音・数値での報酬・煽る演出をしない。落ち着かせることがゴール。
4. **静かに励ます**: ストリークや棒グラフは、達成を煽るのではなく、そっと自己肯定につながる程度に。
